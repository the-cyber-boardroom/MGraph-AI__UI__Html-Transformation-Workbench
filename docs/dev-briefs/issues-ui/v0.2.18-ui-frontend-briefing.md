## 1. Graph Traversal API ✅ NEW

**Endpoint:** 
```
GET /nodes/api/nodes/{node_type}/{label}/graph?depth=N
```

**Purpose:** Fetch a node with all connected nodes for graph visualization.

**Parameters:**
| Parameter | Type | Description |
|-----------|------|-------------|
| `node_type` | string | Type of root node: `bug`, `task`, `feature`, `version`, etc. |
| `label` | string | Label of root node: `Bug-1`, `Feature-11`, `Version-1`, etc. |
| `depth` | int | Link hops to traverse (default: 1, max: 3) |

**Example Request:**
```javascript
const response = await fetch('/nodes/api/nodes/feature/Feature-11/graph?depth=2');
const graph = await response.json();
```

**Response:**
```json
{
  "success": true,
  "root": "Feature-11",
  "depth": 2,
  "nodes": [
    { "label": "Feature-11", "title": "Issue Editor", "node_type": "feature", "status": "in-progress" },
    { "label": "Task-2", "title": "Edit form component", "node_type": "task", "status": "todo" },
    { "label": "Task-3", "title": "Comments UI", "node_type": "task", "status": "todo" },
    { "label": "Version-1", "title": "v0.1.3", "node_type": "version", "status": "in-progress" }
  ],
  "links": [
    { "source": "Feature-11", "target": "Task-2", "link_type": "has-task" },
    { "source": "Feature-11", "target": "Task-3", "link_type": "has-task" },
    { "source": "Version-1", "target": "Feature-11", "link_type": "has-feature" }
  ]
}
```

**Notes:**
- Traverses both outgoing AND incoming links
- Handles cycles (won't infinite loop)
- Depth is capped at 3 to prevent expensive queries

**UI Integration:**
```javascript
// In graph-service.js
async getNodeGraph(nodeType, label, depth = 1) {
    const response = await fetch(`/nodes/api/nodes/${nodeType}/${label}/graph?depth=${depth}`);
    return response.json();
}
```

## 2. Properties Deep Merge ✅ FIXED

**What Changed:** PATCH now does deep merge on `properties` instead of replacing them.

**Before (v0.2.17 - DANGEROUS):**
```javascript
// This would LOSE existing properties!
await updateNode('Task-1', { properties: { comments: [newComment] } });
// Result: severity, component, etc. all GONE
```

**After (v0.2.20 - SAFE):**
```javascript
// Now safe to send partial properties
await updateNode('Task-1', { properties: { comments: [newComment] } });
// Result: existing properties preserved, comments added
```

**UI Impact:**
- You NO LONGER need to fetch the full node before updating properties
- Can safely add comments without losing other property data
- Nested objects are also merged recursively

**Example - Adding Comments:**
```javascript
// OLD WAY (no longer needed):
const node = await getNode(label);
const properties = { ...node.properties };
properties.comments = [...(properties.comments || []), newComment];
await updateNode(label, { properties });

// NEW WAY (simpler):
await updateNode(label, { 
    properties: { 
        comments: [...existingComments, newComment] 
    } 
});
```

## 3. Create Node Safety Check ✅ FIXED

**What Changed:** `POST /nodes/api/nodes` now checks if label already exists before creating.

**Problem Solved:** If `_index.json` was out of sync (said next=4 but Task-4 existed), creating a new task would overwrite the existing one.

**Now:** Backend automatically finds the next available index, even if `_index.json` is wrong.

**UI Impact:** No changes needed - this is a backend safety net.

---

## 4. Multiline Descriptions ✅ FIXED

**What Changed:** Newlines in descriptions are now preserved through save/load cycles.

**Before:** `"Line 1\n\nLine 2"` → `"Line 1__Line 2"` (underscores!)
**After:** `"Line 1\n\nLine 2"` → `"Line 1\n\nLine 2"` (preserved!)

**UI Impact:** Markdown in descriptions will render correctly now.

## graph-service.js Updates

Add this method to your graph service:

```javascript
/**
 * Get node with connected nodes for graph visualization
 * @param {string} nodeType - Type of root node (bug, task, feature, etc.)
 * @param {string} label - Label of root node (Bug-1, Feature-11, etc.)
 * @param {number} depth - Link hops to traverse (default: 1, max: 3)
 * @returns {Promise<{success, root, nodes, links, depth}>}
 */
async getNodeGraph(nodeType, label, depth = 1) {
    try {
        const response = await fetch(
            `${this.baseUrl}/nodes/api/nodes/${nodeType}/${label}/graph?depth=${depth}`
        );
        return await response.json();
    } catch (error) {
        console.error('Failed to fetch node graph:', error);
        return { success: false, nodes: [], links: [], message: error.message };
    }
}
```
