## Bug Fixes (High Priority)

### 1. Properties Deep Merge in PATCH

**File:** `service/issues/graph_services/Node__Service.py`

**Problem:** The current implementation does shallow merge:
```python
if request.properties is not None:
    node.properties.update(request.properties)
```

This causes data loss when UI sends partial properties updates.

**Example:**
```
# Existing node.properties:
{ "severity": "high", "component": "auth" }

# UI sends (to add a comment):
{ "properties": { "comments": [{...}] } }

# Result (WRONG):
{ "comments": [{...}] }  # severity and component LOST
```

**Fix:** Implement deep merge for properties:

```python
def update_node(self, node_type, label, request) -> Schema__Node__Update__Response:
    node = self.repository.node_load(node_type=node_type, label=label)
    if node is None:
        return Schema__Node__Update__Response(success=False, message=f'Node not found: {label}')

    # Apply updates - use truthiness check for Safe_Str fields
    if request.title:
        node.title = request.title
    if request.description:
        node.description = request.description
    if request.status:
        node.status = request.status
    if request.tags is not None:
        node.tags = list(request.tags)
    
    # Deep merge properties instead of shallow update
    if request.properties is not None:
        node.properties = self.deep_merge_properties(node.properties, request.properties)

    node.updated_at = Timestamp_Now()
    # ... rest of method


def deep_merge_properties(self, existing: dict, updates: dict) -> dict:
    """Deep merge properties, preserving existing keys not in updates."""
    result = dict(existing) if existing else {}
    
    for key, value in updates.items():
        if key in result and isinstance(result[key], dict) and isinstance(value, dict):
            result[key] = self.deep_merge_properties(result[key], value)
        else:
            result[key] = value
    
    return result
```

**Test Case:**
```python
def test_update_node__properties_deep_merge(self):
    # Create node with existing properties
    create_request = Schema__Node__Create__Request(
        title='Test', 
        node_type='task',
        properties={'severity': 'high', 'component': 'auth'}
    )
    create_response = self.node_service.create_node(create_request)
    label = create_response.node.label
    
    # Update with partial properties (add comments)
    update_request = Schema__Node__Update__Request(
        properties={'comments': [{'text': 'test comment'}]}
    )
    update_response = self.node_service.update_node(
        node_type='task', label=label, request=update_request
    )
    
    # Verify deep merge - original properties preserved
    assert update_response.node.properties['severity'] == 'high'
    assert update_response.node.properties['component'] == 'auth'
    assert update_response.node.properties['comments'] == [{'text': 'test comment'}]
```

### 2. Multiline Description Sanitization

**File:** `schemas/graph/Safe_Str__Graph_Types.py` (or `Schema__Node.py`)

**Problem:** `Safe_Str__Text` sanitizes newlines to underscores. When a node is loaded and saved (even without description changes), newlines are corrupted:

```
Before: "Create a system.\n\nThe system should:\n- Feature 1"
After:  "Create a system.__The system should:_- Feature 1"
```

**Fix:** Already identified — use `Safe_Str__Multiline` for description field:

```python
import re
from osbot_utils.type_safe.primitives.core.Safe_Str import Safe_Str
from osbot_utils.type_safe.primitives.core.enums.Enum__Safe_Str__Regex_Mode import Enum__Safe_Str__Regex_Mode


class Safe_Str__Multiline(Safe_Str):
    """Safe string type that preserves newlines for multiline content."""
    max_length        = 50000
    regex             = re.compile(r'[^\x20-\x7E\n\r\t]')  # Allow printable + newlines + tabs
    regex_mode        = Enum__Safe_Str__Regex_Mode.REPLACE
    strict_validation = False
```

Then in `Schema__Node.py`:
```python
description: Safe_Str__Multiline  # Was: Safe_Str__Text
```

**Note:** User mentioned they named it `Safe_Str__Issue__Node__Description` as part of a wider refactoring. Confirm naming convention.

## New Endpoint (Medium Priority)

### 3. Graph Traversal API

**File:** `fast_api/routes/Routes__Nodes.py` (new method)
**File:** `service/issues/graph_services/Node__Service.py` (new method)

**Purpose:** UI needs to fetch a node with its connected nodes for graph visualization.

**Endpoint:**
```
GET /nodes/api/nodes/{node_type}/{label}/graph?depth=1
```

**Parameters:**
- `node_type`: Type of the root node (bug, task, feature, etc.)
- `label`: Label of the root node (Bug-1, Feature-11, etc.)
- `depth`: Number of link hops to traverse (default: 1, max: 3)

**Response Schema:**

```python
class Schema__Graph__Node(Type_Safe):
    label     : Safe_Str__Node_Label
    title     : Safe_Str__Text
    node_type : Safe_Str__Node_Type
    status    : Safe_Str__Status

class Schema__Graph__Link(Type_Safe):
    source    : Safe_Str__Node_Label
    target    : Safe_Str__Node_Label
    link_type : str  # verb like "has-task", "blocks"

class Schema__Graph__Response(Type_Safe):
    success   : bool
    root      : Safe_Str__Node_Label
    nodes     : List[Schema__Graph__Node]
    links     : List[Schema__Graph__Link]
    message   : str = ''
```

**Example Response:**
```json
{
  "success": true,
  "root": "Feature-11",
  "nodes": [
    { "label": "Feature-11", "title": "Issue Editor", "node_type": "feature", "status": "in-progress" },
    { "label": "Task-2", "title": "Create issue edit form", "node_type": "task", "status": "todo" },
    { "label": "Task-3", "title": "Comments UI", "node_type": "task", "status": "todo" },
    { "label": "Version-1", "title": "v0.1.3", "node_type": "version", "status": "in-progress" }
  ],
  "links": [
    { "source": "Feature-11", "target": "Task-2", "link_type": "has-task" },
    { "source": "Feature-11", "target": "Task-3", "link_type": "has-task" },
    { "source": "Version-1", "target": "Feature-11", "link_type": "has-feature" }
  ],
  "message": ""
}
```

**Implementation Approach:**

```python
# In Node__Service

def get_node_graph(self, node_type: Safe_Str__Node_Type, 
                   label: Safe_Str__Node_Label,
                   depth: int = 1) -> Schema__Graph__Response:
    
    root_node = self.repository.node_load(node_type=node_type, label=label)
    if root_node is None:
        return Schema__Graph__Response(success=False, root=label, 
                                       nodes=[], links=[], 
                                       message=f'Node not found: {label}')
    
    visited_labels = set()
    nodes = []
    links = []
    
    self._traverse_graph(root_node, depth, visited_labels, nodes, links)
    
    return Schema__Graph__Response(success=True, root=label,
                                   nodes=nodes, links=links)

def _traverse_graph(self, node: Schema__Node, depth: int,
                    visited: set, nodes: list, links: list):
    if str(node.label) in visited or depth < 0:
        return
    
    visited.add(str(node.label))
    nodes.append(Schema__Graph__Node(
        label=node.label,
        title=node.title,
        node_type=node.node_type,
        status=node.status
    ))
    
    if depth == 0:
        return
    
    # Traverse outgoing links
    for link in node.links:
        target_node = self._resolve_link_target(link)
        if target_node:
            links.append(Schema__Graph__Link(
                source=node.label,
                target=target_node.label,
                link_type=link.link_type
            ))
            self._traverse_graph(target_node, depth - 1, visited, nodes, links)
    
    # Also find incoming links (nodes that link TO this node)
    incoming = self._find_incoming_links(node.label)
    for source_node, link_type in incoming:
        if str(source_node.label) not in visited:
            links.append(Schema__Graph__Link(
                source=source_node.label,
                target=node.label,
                link_type=link_type
            ))
            self._traverse_graph(source_node, depth - 1, visited, nodes, links)
```

**Route:**
```python
# In Routes__Nodes

@router.get('/api/nodes/{node_type}/{label}/graph')
def get_node_graph(self, node_type: str, label: str, depth: int = 1):
    if depth > 3:
        depth = 3  # Cap to prevent expensive traversals
    
    response = self.service.get_node_graph(
        node_type=Safe_Str__Node_Type(node_type),
        label=Safe_Str__Node_Label(label),
        depth=depth
    )
    return response.json()
```

## Enhancement (Low Priority)

### 4. Comments Validation

**Purpose:** Ensure comments in `properties.comments` have valid structure.

**Not blocking:** UI can work without this. But would be nice to validate:
- `id`: string (UUID format)
- `author`: string ('human' or 'claude-code' or similar)
- `text`: string (non-empty)
- `created_at`: int (timestamp)
- `updated_at`: int (optional)

**Approach:** Add validation in `Node__Service.update_node()` if properties contains comments:

```python
def _validate_comments(self, comments: list) -> bool:
    if not isinstance(comments, list):
        return False
    
    for comment in comments:
        if not isinstance(comment, dict):
            return False
        if 'id' not in comment or 'author' not in comment or 'text' not in comment:
            return False
        if 'created_at' not in comment:
            return False
    
    return True
```
