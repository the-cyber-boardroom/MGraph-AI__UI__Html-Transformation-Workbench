#### Bug-3: Left hand side menu doesn't collapse completely
**Priority:** Medium
**Effort:** M (Medium)

**Description:**
The minimize button closes the menu but leaves the width the same. Should collapse to just icons.

**Approach:**

2. When collapsed, show only icons (no text labels)
3. Width reduces to ~50px (icon width + padding)
4. Save collapsed state to localStorage
5. Hover could temporarily expand to show labels

```javascript
// Shell state
this._navCollapsed = false;

// Toggle collapse
toggleNavCollapse() {
    this._navCollapsed = !this._navCollapsed;
    this.$leftNav.classList.toggle('collapsed', this._navCollapsed);
    localStorage.setItem('nav-collapsed', this._navCollapsed);

// CSS
.shell-left-nav.collapsed {
    width: 50px;
}
.shell-left-nav.collapsed .nav-item-label,

    display: none;
}
```

```javascript
// Add comment
async addComment(nodeLabel, commentText) {
    const node = await this.graphService.getNode(nodeLabel);
    const comments = node.properties?.comments || [];
    comments.push({
        id: crypto.randomUUID(),
        author: 'human',
        text: commentText,
        created_at: Date.now()
    });
    await this.graphService.updateNode(nodeLabel, { properties: { comments } });
}
```

#### Feature-11: Capture current issue in navbar / persist location
**Priority:** Medium
**Effort:** M (Medium)

**Description:**
When page refreshes, don't lose the current location. Currently goes to v0.1.2/index.html.

**Questions:**
- Should this use URL hash routing? (e.g., `#/kanban` or `#/issue/Bug-1`)
- Or localStorage to remember last location?
- Should individual issue views be bookmarkable?

**Possible approaches:**

1. **Hash-based routing:**
   ```javascript
   // On navigation
   window.location.hash = `/issue/${nodeLabel}`;

   // On load
   const route = window.location.hash.slice(1);
   if (route.startsWith('/issue/')) {
       const label = route.split('/')[2];
       this.router.navigate('node-detail');
       this.events.emit('navigate-to-node', { label });
   }
   ```

2. **localStorage persistence:**
   ```javascript
   // On navigation
   localStorage.setItem('last-route', { app: 'node-detail', nodeLabel: 'Bug-1' });

   // On load
   const lastRoute = localStorage.getItem('last-route');
   if (lastRoute) { /* restore */ }
   ```

**Recommendation:** Use hash routing for bookmarkability
