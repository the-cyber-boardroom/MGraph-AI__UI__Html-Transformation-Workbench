## Key Design Decisions

### 1. MGraphDB Storage Location
**Location:** `.issues/indexes/`
**Naming:** `{name}.mgraph.json`

```
.issues/
├── indexes/
│   ├── issues.mgraph.json           # Main issue graph
│   ├── issues-by-type.mgraph.json   # Future: filtered by type
│   └── issues-active.mgraph.json    # Future: only active issues
```

Rationale: Separate `indexes/` folder keeps cache/computed data separate from source data. Multiple `.mgraph.json` files will represent pre-computed queries/views.

### 2. Sync Strategy
- **Lazy sync** on first query (not on startup)
- **Trigger resync** on root change
- **Incremental sync** on node save/delete (future optimization)

### 3. URL Format (Relative to Root)
URLs are **relative to the current root context**.

| Root Setting | Issue Path | URL |
|--------------|------------|-----|
| (default) | Project-1/Version-1/Task-6 | `#/issue/Project-1/Version-1/Task-6` |
| Project-1 | Version-1/Task-6 | `#/issue/Version-1/Task-6` |
| Project-1/Version-1 | Task-6 | `#/issue/Task-6` |

### 4. Label Format
**New default:** Hyphenated labels like `User-Story-1`
**Backward compatible:** Read both `UserStory-1` and `User-Story-1`

### 5. Config Backup
Not needed — git tracks all changes to config files.

### B10: Recursive Node Discovery
**Priority:** P0 (Critical)
**Blocks:** U6, U7

**Current behavior:**
```python

def nodes_list_labels(self):
    for node_type in self.list_node_types():
        type_folder = self.path_handler.path_for_type_folder(node_type)
        # Lists only direct children of type folder
```

**New behavior:**
```python
def nodes_list_all(self, root_path: str = None) -> List[NodeInfo]:
    """Find all issue.json files recursively, including nested issues/ folders."""
    all_paths = self.storage_fs.files__paths()
    nodes = []
    
    # Filter by root if specified
    search_prefix = f"{root_path}/" if root_path else ""
    
    for path in all_paths:
        if search_prefix and not path.startswith(search_prefix):
            continue
            
        if path.endswith('/issue.json'):
            folder_path = path.rsplit('/issue.json', 1)[0]
            label = folder_path.rsplit('/', 1)[-1]
            
            # Skip system folders
            if label in ('config', 'data', 'issues', 'indexes', '.issues'):
                continue
            
            nodes.append(NodeInfo(label=label, path=folder_path))
    
    return nodes
```

**Files:** `Graph__Repository.py`, `Node__Service.py`

### B11: Node Loading by Path
**Priority:** P0 (Critical)
**Blocks:** U6, U7

**New method:**
```python
def node_load_by_path(self, path: str) -> Schema__Node:
    """Load node from explicit path (relative to storage root)."""
    issue_file = f"{path}/issue.json"
    
    if self.storage_fs.file__exists(issue_file):
        content = self.storage_fs.file__str(issue_file)
        return Schema__Node.from_json(json_loads(content))
    
    return None
```

**Fallback search by label:**
```python
def node_load(self, label: str) -> Schema__Node:
    """Load node by label, searching all folders."""
    all_paths = self.storage_fs.files__paths()
    
    for path in all_paths:
        if path.endswith(f'/{label}/issue.json'):
            return self.node_load_by_path(path.rsplit('/issue.json', 1)[0])
    
    return None
```

**Files:** `Graph__Repository.py`, `Node__Service.py`

### B14: Path-Based Node Endpoint
**Priority:** P1
**Blocks:** U6

**New endpoint:**
```
GET /nodes/api/node/by-path?path={relative_path}
```

**Example requests:**
```
# Full path from root
GET /nodes/api/node/by-path?path=Project-1/Version-1/Feature-12

# When root is set to Project-1
GET /nodes/api/node/by-path?path=Version-1/Feature-12
```

**Path resolution logic:**
```python
def resolve_hierarchical_path(self, root: str, path: str) -> str:
    """Convert 'Project-1/Version-1/Task-6' to filesystem path."""
    segments = path.split('/')
    
    if root:
        # Start from root path
        result = root
        start_idx = 0
    else:
        # Find first segment in data/ folders
        first_label = segments[0]
        result = self.find_node_folder(first_label)
        start_idx = 1
    
    # Each subsequent segment is in issues/ subfolder
    for segment in segments[start_idx:]:
        result = f"{result}/issues/{segment}"
    
    return result
```

### B22: Hyphenated Label Support
**Priority:** P2

**New label generation:**
```python
def generate_label(self, node_type: str, index: int) -> str:
    """Generate 'User-Story-1' instead of 'UserStory-1'."""
    # 'user-story' → 'User-Story'
    display_type = '-'.join(word.capitalize() for word in node_type.split('-'))
    return f"{display_type}-{index}"
```

**Backward compatible reading:**
- Accept both `UserStory-1` and `User-Story-1` on read
- New issues always use hyphenated format
